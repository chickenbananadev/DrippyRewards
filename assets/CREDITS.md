# Third-party assets

## assets/fx-burst.png — explosion effect sheet
- **Source:** "Explosion Sheet" by StumpyStrust, published on OpenGameArt.org
  (original file `boom3.png`, 1024x1024, 64 frames).
- **License:** CC0 1.0 Universal (public domain). No attribution required —
  credited here as good practice.
- **Modifications:** re-cut to the 24 fireball/smoke frames, cropped to the
  union bounding box, scaled to 80x80 per frame (6x4 sheet), and warm-tinted
  toward the $DRIPPY gold palette.

Everything else in the game — all scenery, materials, skylines, props and
effects other than this sheet and the original Drippy character art — is
generated procedurally in code (see the "PROCEDURAL ART LAYER" section of
game.html).
